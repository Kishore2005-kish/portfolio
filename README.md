# Kishore P Portfolio

Premium product-focused AI engineering portfolio built with Next.js 15, TypeScript, Tailwind CSS v4, Framer Motion, GSAP, Lenis, and React Three Fiber.

## Run Locally

```bash
npm install
npm run dev
```

## Content

Edit `src/data/portfolio.ts` for profile links, projects, achievements, skills, and image replacement paths.

## Assets

The resume is served from `public/Kishore.p_Resume.pdf`. Placeholder image slots are documented in `public/placeholders/IMAGE_MAP.md`.
